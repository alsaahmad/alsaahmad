### 🚨 AEGIS — AI Emergency Response Platform
*Flagship project*

A collaborative, AI-driven emergency operating system — an SOS event triggers severity classification, ambulance dispatch, hospital matching, and a live command-center view.

**My contribution:** the AI/agent microservice (`aegis-ai`), built as part of a team — severity prediction, hospital & ambulance recommendation agents, a command/response agent, and an orchestrator tying them together with decision-trace logging for explainability, plus a YOLO + OpenCV vision pipeline for detecting incidents from video. Designed against a frozen API contract for integration with the team's Spring Boot / Next.js platform.

`Python` `FastAPI` `YOLOv11` `OpenCV` `Spring Boot` `Next.js` `PostgreSQL`
